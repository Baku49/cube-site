# ・全般

3～6人で遊ぶことができる

この文書の全文や、カードテキストやルールに関して、遊んでいる間いつでも調べてよい

超次元ゾーンに置かれるカードも裏面が隠れるスリーブに入っているが、プレイヤーは1面を見られる間いつでも全ての面を確認できる

3D覚醒や3D龍解のカードはドラフト時はプロキシを用いるが、いつでも全ての面を確認できる

# ・ドラフトのルール

20枚のパックを人数×3個作り、通常のブースタードラフトを行う

表面になるために複数のカードが必要なゲーム開始時にバトルゾーンに存在出来るカードをドラフトしたプレイヤーは、全てのドラフトが終了した後で、それらを構成するカードを1枚ずつカードプールに加える

デュエリストをドラフトしたプレイヤーは、全てのドラフトが終了した後で、そのデュエリストに対応するデュエルメイト3種類を1枚ずつカードプールに加える

# ・構築のルール

ピックしたカード及び、配布カードである「メタルポンの助」6枚がカードプールである

40枚のメインデッキ、0～8枚の超次元ゾーンに置かれるカード、0枚または6枚の超GR、0～1セットのゲーム開始時にバトルゾーンに存在出来るカードを構築する

ゲーム開始時にバトルゾーンに存在出来るカードは、その種類を問わず、メインデッキの枚数には含めない

余剰のカードはサイドボードとして持つ

サイドボーディングの機会は原則として設けないが、プレイヤー全員が同意するのであればゲーム後にカードの入れ替えを行ってもよい

カードプールにあるメインデッキに入るカードを全て使ってもメインデッキが40枚に満たないなら、入れられるカード全てでメインデッキを構築する

殿堂入り・プレミアム殿堂・使用禁止カードもデッキに入れられる

# ・対戦のルール

原則として最新の殿堂ゼロの公式ルールで行う

ゲームオリジナルカードの裁定について決定できない状況になった場合は、プレイヤー全員の合意のもと、良心的な判断でゲームを続行する

# ・拡張パックを用いる効果

何らかの拡張パックを用いる場合、代わりにキューブの残りのカードから5枚を取り出してそれを用いる

それらのパックの中のカードの順番は自分が自由に決められる

# ・デュエパーティー

ドラフトを始めるより前に全員の合意があれば、デュエパーティーでプレイしてもよい

デュエパーティーなら、1枚のパートナーと、39枚のメインデッキと、0～8枚の超次元ゾーンに置かれるカード、0枚または6枚の超GR、0～1セットのゲーム開始時にバトルゾーンに存在出来るカードを構築する

指定できるパートナーの条件は、通常のデュエパーティーと同じである

パートナーの色による構築制限のルールは適用されない

超次元ゾーンに置かれるカード、超GR、ゲーム開始時にバトルゾーンに存在出来るカードも使用できる

同名カードを1ターンに何度でもバトルゾーンに出せ、使える

特殊勝利する効果、相手を敗北させる効果、追加ターンを得る効果も働く
