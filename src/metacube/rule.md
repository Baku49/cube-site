# ・メタキューブとは

　メタキューブは、私が管理するマジックザギャザリングのキューブドラフトである。

　メタキューブは主としてコマンダーやその変種ルールで遊ぶ。

　また、メタキューブはいわゆる「パワード」に近いキューブである。ごく一部のカードを除いて、カードパワーの上限を設けていない。そのため、極めて強力なカードがキューブ内に多々存在している。

　なお、このルールにはメタキューブのキューブの内容については記述されていない。キューブの内容については以下のリンクを参照せよ。

　[メタキューブ カードリスト(Cube Cobra)](https://cubecobra.com/cube/list/MetaCube)

# ・メタキューブで遊ぶためには

・プレイ人数

　2人から6人

　ただし、5人は非推奨

　最も推奨する人数は4人

・プレイヤーに求める技能

　マジックの基本的なルールを理解していること

　マジックのテキストを読んで、処理の方法をある程度理解できること

　コマンダーや、選択した場合には双頭巨人戦やプレインチェイス戦やアーチエネミー戦の、基本的なルールを理解していること

・プレイヤーが受け入れる必要があること

　ハウスルールが存在すること

　プロキシの使用

# ・メタキューブを遊ぶにあたって

　メタキューブは「ゲームを楽しむこと」を目的としている限り、以下の行為に一切の制限を設けない。

　・他プレイヤーに助言を求める、または助けを求めている他プレイヤーに助言すること

　・スマートフォンなどの媒体を使って、マジックのルールやカードの情報、メタキューブのルールやカードリスト、その他プレイに関係あるあらゆる情報について調べること

　・他のプレイヤーが納得する範囲内でのプレイの巻き戻し

　・すぐにルール上の結論が出ないようなゲーム状況について、プレイヤー同士でルーリングの判断をすること

　・カードを汚さないような飲食

　また、以下のようなことを禁止する。

　・ゲーム上の情報についての虚言や、他のプレイヤーを錯誤させることを目的とした発言

　・他のプレイヤーが不快に感じるゲーム外の行動

　・知識の少ないプレイヤーに対してゲーム上必要な知識を提供しないこと

　・ライブラリーのカットの強要

　・(多人数戦の場合)ゲーム上正当な理由なく1人のプレイヤーに対して集中して敵対的な行動を選ぶこと

　このルールで定められていないことについても、全てのプレイヤーがプレイを楽しめるよう心がけた行動を求める。

# ・ドラフトの前に決めるべきルール選択肢

　ドラフトを開始する前に、プレイヤー全員の合意のもと、以下の5つのルールから選ぶ。

　1回のドラフトで複数のルールを遊んでもよいが、そのルールの全てをドラフトより前に決定しておく。

　複数の卓に分かれる場合、卓ごとにルールを変えてもよいが、その場合はどのようなグループに別れるかをドラフトより前に決定しておく。

・**(通常の)コマンダー**：ゲーム人数3人以上のコマンダー。

・**デュエルコマンダー**：ゲーム人数2人のデュエルコマンダー。

・**統率者双頭巨人戦**：ゲーム人数4人の、コマンダーかつ双頭巨人戦。

・**統率者プレインチェイス戦**：ゲーム人数3人以上の、コマンダーかつプレインチェイス戦。

・**統率者アーチエネミー戦**：ゲーム人数4人で1人が魔王となる、統率者アーチエネミー戦。

　複数のルールを選んだ場合、ルールを変えるたびにサイドボーディングの機会を設ける。

# ・ドラフトのルール

　1パック目を見る前に、各プレイヤーは、自分のカードプールに《虹色の笛吹き》2枚、《宝石の睡蓮》1枚、《太陽の指輪》1枚、《秘儀の印鑑》1枚《統率の塔》4枚、《寓話の小道》4枚、《祖先の道》4枚を加える。その後、それぞれ用意された背景カードの中から、ランダムに選ばれた2枚を自分のカードプールに加える。

　1つのブースターパックの枚数：**20枚**

　パックの個数：**プレイ人数×3個**

　メタキューブのドラフトの形式は、プレイ人数が3人から6人において共通で通常のドラフトである。3人か4人である場合、プレイヤー全員が同意したなら、代わりにピック2ドラフトを選択してもよい。2人の場合は、「2人用ルール」に書かれている手順で行う。

　ドラフトの段階において、コンスピラシー・ドラフトのルールを適用する。そのため、一部のカードはドラフトのルールに影響を与える効果を発揮する。

# ・デッキ構築のルール

　統率者の指定について、以下の3段階の手順で決定する。

①最初の統率者を1枚指定する。

　最初の統率者として選べるのは「伝説のクリーチャー」か「伝説の機体」か「パワーとタフネスを持つ伝説の宇宙船」か「**伝説のプレインズウォーカー**」である。

②最初の統率者が「共闘」を持つなら、共闘する統率者を追加で1枚指定する。

　通常の統率者のルールと同様に、追加で指定できるのは「共闘」を持つカードのみである。

③この時点で統率者の**全て**がプレインズウォーカーなら、そのプレインズウォーカーは「誓い破り」である(第2面のみがプレインズウォーカーであるカードも、ここではプレインズウォーカーとして扱う)。

　統率者の全てが誓い破りなら、その誓い破りのそれぞれについて、固有色の全てがその誓い破りの固有色に含まれるインスタントかソーサリーであるカード1枚を追加で統率者に指定する。

④この時点で統率者の固有色の合計が2色以下なら、追加で以下の枚数だけ、背景カードを統率者にしてする。

　背景を指定する前の固有色の合計が…

　無色か1色：2枚

　2色：1枚

　以降のデッキ構築のルールは、概ねコマンダーと同様である。コマンダーのルールと同じ部分についてはこのルールでは記述しない。([コマンダー - MTG Wiki](http://mtgwiki.com/wiki/%E3%82%B3%E3%83%9E%E3%83%B3%E3%83%80%E3%83%BC) などを参照せよ)

　ただし、以下の点でコマンダーと異なる。

　・デッキを構築する際に使用できるカードはあなたのカードプールのカード、及び無制限に使用できる《平地》、《島》、《沼》、《山》、《森》である。

　・デッキの最小サイズは**統率者を含む50枚**である。(デッキ枚数の上限はない)

　・ハイランダールールは適用されず、同名カードを何枚でもデッキに入れることができる。(同名カードを5枚以上入れてもよい)

　・禁止カードのルールは適用されない。

　・デッキに入れなかったカードは全てサイドボードとする。(サイドボードのカードは固有色のルールに従っている必要はない)

# ・ゲームのルール

## ・全般

　基本的には総合ルールに従ってゲームを行う。

　コマンダーの**統率者のルール**を適用する。

　多人数戦であっても、フリーマリガンは行わない。

　通常のコマンダーと異なり、自分のサイドボードのカードをゲームの外部として用いることができる。そのカードが統率者の固有色の構築ルールに従っている必要はない。

　サイドボードの入れ替えによってデッキに入れることができるカードは、固有色のルールに従っているカードのみである。

　各プレイヤーは自身の統率領域に《荒地》4枚がある状態でゲームを開始する。このカードはヒュージ・リーダーズのルールと同様に「拠点」としてのルールを受ける。

　誓い破りのルールを部分的に用いる。

　トレードマークの呪文は、対応する誓い破りをコントロールしている場合にのみ統率領域から唱えられる。

　「誓い破り」や「トレードマークの呪文」はカードそのものが持つ属性であり、その属性は「統率者」という属性を持つことを妨げない。

　コンスピラシー・ドラフトのルールのうち、ドラフトに関するルールと策略のルールを用いる。

　アン・ゲームのルールを適用する。ただし、数として選べるのは0以上の整数のみである。支払えるマナやライフは、カードのテキストで½点を支払えることが示されていない限り、0以上の整数のみである。色として選べるのは通常のマジックに存在する5つの色のみである。文章欄を書き換える効果は、カード実物の代わりに、公式サイトのエラッタ告知記事に記載の最新のエラッタ後の文章→WISDOM GUILDに記載の日本語のルール・テキスト→MTG Wikiに記載の日本語のルール・テキスト→カードに貼り付けられているシールに書かれた日本語の文章→オラクル→カードに書かれた日本語以外の文章の優先度で参照して書き換える。

　マジックのカードとして選ぶことができるカードは、「エターナルのカードプールに含まれるカード（カードを放り投げるカード・人種または文化に対し攻撃的なカード・アンティに関連するカード以外の禁止カードを含む）」か「メタキューブのカードプールに含まれるカード」のいずれかに当てはまるカードである。

## ・選択したルールごとの事項

　統率者ダメージのルールがある場合、トレードマークの呪文については統率者ダメージを計算しない。

　通常のコマンダーの場合：

　コマンダーの多人数戦のルール(多人数戦の無差別戦、「複数への攻撃」選択ルール)、「開始時のライフの総量は**30**」のルールを用いる(統率者ダメージのルールは用いない)。

　デュエルコマンダーの場合：

　「開始時のライフの総量は**30**」である(統率者ダメージのルールは適用されない)。その他の対戦のルールは通常の2人戦と同じである。

　双頭巨人戦の場合：

　通常のコマンダーの場合と同様の、統率者ダメージのルール、「チームの開始時のライフの総量は**30**」を採用することを除き、双頭巨人戦と同じである(統率者ダメージのルールは用いない)。

　プレインチェイス戦の場合：

　通常のコマンダーのルールに加えて、プレインチェイス戦のルールを用いる。

　単一次元の選択ルールを使用する。

　次元デッキの構築についてのルールは適用されず、代わりに用意された次元デッキを使用する(複数卓に分かれる場合には、用意された次元デッキを無作為に分割してそれぞれ用いる)。

　統率者アーチエネミー戦の場合：

　統率者アーチエネミー戦のルールを用いる(通常通り、初期ライフは60であり、統率者ダメージのルールは適用されない)。ただし、ゲームの外部のルールについては、このルールに書かれたルールを適用する。

　計略デッキの構築についてのルールは適用されず、代わりに用意された計略デッキを用いる。

#### 《Nocturno of Myra's Marvels》

### ・テキストに書かれている数を変更する能力を持つカード

　呪文の解決時に、呪文能力で決められている対象の数とその呪文が実際に対象としているオブジェクトの数が異なる場合には以下のように処理する。

呪文能力で決められている対象が多い：解決時に、呪文能力で決められている数になるように新たな対象を選んで、対象にしているものとする。選べる対象が不足することにより、呪文能力で決められている数の対象を選べない場合、対象不適正により立ち消える。

呪文能力で決められている対象の数が少ない：解決時に、実際に対象としているオブジェクトから呪文能力で決められている対象の数のオブジェクトを選び、それについてのみ処理を行う。ただし、呪文能力で決められている対象の数が0以下である場合、対象不適正により立ち消える。

　また、数値が書き換えられることによって0による除算が発生した場合、その結果の値は無限大になる。

　また、0個のオブジェクトや0の数値に関するイベントは起こらず、それらに関する条件は満たされることはない。ただし、このルールの例外として、0個のオブジェクトや0の数値に関するコストは、何もせずに支払うことができる。

### ・「マジックのブースターパックを1つ開ける」効果を持つカード

　キューブの残りからカードを15枚取り出し(足りない場合は取り出せる分だけ取り出す)、ゲームの外部に1つの束として置き、それらのカードを「開けた」カードとして扱う。ゲーム終了時、取り出したそれらのカードを全て取り除く。

　これらのカードのオーナーは、その効果のコントローラーである。

　これらのカードはゲームの外部のカードであるため、固有色の構築のルールは適用されない。

### ・《Frankie Peanuts》

　質問できるのは、ゲーム内容について各プレイヤーが合意できる程度に形式的に回答できるものだけである。(例えば、「あなたの手札に終盤に使ったら強いカードはありますか？」という質問は、そのYES/NOの回答について参加プレイヤーの間で意見が割れる可能性があるため、することができない。)

　自己言及となるような質問はできない。

　回答によって強制されるのはゲーム内の行動のみである。これについて、投了することはゲーム内の行動に含めない。

　回答した後のゲーム状況の変化によって、質問の答えに従うことが不可能になったなら、従えなくなるたびに、その旨を各プレイヤーに伝えればよい。

# ・2人用ルール

　ドラフトはホースマンドラフトで行う。手順は以下の通りである。

　①：キューブをシャッフルし、19枚の山札を12個作る。

　②：無作為な方法で先攻と後攻を決める。

　③：残っている山札から1つを無作為に選び、各プレイヤーはその山札の上から5枚のカードをそれぞれに配り、手札とする(自分のみが確認できる)。

　④：その山札の上から9枚を公開して置き、場札とする。

　⑤：先攻から交互に「自分の手札1枚と場札1枚を交換する」という手順を、お互いが3回交換するまで繰り返す(交換は必ず行わなければならない)。

　⑥：交換が終わったら、それぞれ手札をカードプールに加える(コンスピラシー・ドラフトのルールにより「表向きでドラフト」する場合、この時に表向きにする)。その後、場札は避けておく(ストアやファンドに戻すことはせず、以後使用しない)。

　⑦：③〜⑥の手順を、毎回先攻と後攻を入れ替えて、12回行う。

　・以降のデッキ構築やゲームのルールは通常と同じである。

　・2人戦の場合には、コンスピラシー・ドラフトのルールでカードを表向きにドラフトすることはできない。
