# ・総則

プレイ人数は2人から6人である

カードが1〜3枚がセットになった「パイル」という単位でドラフトを行う

# ・ドラフトのルール

20個のパイルを1パックとして、1人3パック分のドラフトを行う

2人戦の場合、代わりに場のパイル9枚、手札5枚、交換回数3回、出番12周のホースマンドラフトを行う

# ・構築のルール

ドラフトしたパイルに含まれるカード及び無制限に使用できる基本エネルギーで構築を行う

1つのパイルに含まれるカードの一部だけを入れてもよい

同名カードを5枚以上入れてもよい

ACE SPECのカードを2枚以上デッキに入れてもよい

同名のプリズムスターのカードを2枚以上デッキに入れてもよい

かがやくポケモンを2枚以上デッキに入れてもよい

# ・対戦のルール

特殊能力・ポケパワー・ポケボディー・特性は全て同じものであり、そのうちに1つ以上に働く効果はそれら全てに働く

旧裏のトレーナーのカードは、トレーナーズであるが、トレーナーズのどの種類にも含まれない

これらのカードは自分の番に何回でも使え、自分の初めの番にと使える

旧裏のトレーナーに働く効果は、トレーナーズ全てに働く

ベイビィポケモンはルールを持つポケモンである

ベイビィポケモンのルールは特性ではない

一部のカードは、エラッタを行う前の古いテキストを使って処理する
